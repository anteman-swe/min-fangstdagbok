# Min Fångstdagbok

jag ska bygga en webbapp i ett skolprojekt där vi ska skapa en app (FiskeExperten). 
första/startsidan ska det vara en inloggsida.
sen kanske efter, kommer man kanske till en karta där man kan öppna och se bilder på fångst av bilder, kanske något förmulär och en lista under det med alla fångster. jag vill ju mest egentligen ha ideeer för design. jag vet inte hur mycket du kan se men jag skickar min kanban tavla. vi ska skapa det i techstack: Spring Boot, Spring Security, Spring JPA, Hibernate Spatial, Thymeleaf, TailwindCSS, en container med Postgres/PostGIS för spatial data och en container med Garage för S3-tjänsten. Senare behöver vi välja vilken AI vi ska koppla in
